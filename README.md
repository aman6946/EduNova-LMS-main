# EduNova - AI Powered LMS

## Overview
EduNova is a Learning Management System built using the MERN stack that enables users to explore courses, purchase content, and manage their learning journey.

## Features
- User authentication with JWT
- Course management
- Payment integration
- AI-powered learning assistance
- Responsive UI

## Tech Stack
Frontend:
- React.js
- Redux Toolkit
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
